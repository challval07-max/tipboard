# Panduan Deploy TipBoard — langkah demi langkah (buat user)

Semua langkah di file ini hanya bisa dilakukan dari akun/wallet kamu sendiri.
Urutan: klaim Agent ID → deploy kontrak → verifikasi → pasang website → submit.

## 0. Persiapan

- [ ] **Klaim Agent ID** di aplikasi Binance: Wallet → banner Agent ID di homepage → klaim nama `.ai` kamu (1 orang 1 nama, tidak bisa dipindah).
- [ ] Wallet browser (MetaMask / Binance Wallet) terhubung ke **BNB Chain mainnet** (chain ID 56).
- [ ] Saldo BNB sedikit untuk gas deploy — 0,01 BNB sudah lebih dari cukup (deploy kontrak ini kecil, biayanya jauh di bawah itu).

## 1. Deploy kontrak via Remix (±5 menit)

1. Buka https://remix.ethereum.org
2. Di File Explorer, buat file baru bernama `TipBoard.sol`, lalu paste SELURUH isi file `TipBoard.sol` dari folder ini.
3. Buka tab **Solidity Compiler** (ikon kedua):
   - Compiler: **0.8.20**
   - Centang **Enable optimization** (200 runs)
   - Klik **Compile TipBoard.sol** → harus muncul centang hijau tanpa error.
4. Buka tab **Deploy & Run Transactions** (ikon ketiga):
   - Environment: **Injected Provider** (wallet kamu akan pop-up, hubungkan)
   - Contract: **TipBoard**
   - Klik **Deploy** → konfirmasi transaksi di wallet kamu.
5. Setelah sukses, kontrak muncul di "Deployed Contracts". **Copy alamat kontraknya** (0x...) — simpan baik-baik, alamat ini dipakai di semua langkah berikutnya.

## 2. Pasang alamat kontrak ke website

1. Buka `web/index.html`, cari baris:
   `const TIPBOARD_ADDRESS = "PASTE_DEPLOYED_CONTRACT_ADDRESS_HERE";`
2. Ganti dengan alamat kontrak dari langkah 1, simpan file.

## 3. Verifikasi source code di BscScan (syarat lomba)

1. Buka https://bscscan.com/address/ALAMAT-KONTRAK-KAMU → tab **Contract** → **Verify and Publish**.
2. Isi:
   - Compiler Type: **Solidity (Single file)**
   - Compiler Version: **v0.8.20+commit.a1b79de6**
   - License: **MIT**
3. Paste isi `TipBoard.sol`, lanjutkan. Di halaman berikutnya:
   - Optimization: **Yes**, Runs: **200**
4. Submit → tunggu sampai muncul "Successfully generated ByteCode and ABI" / centang hijau di tab Contract.

## 4. Publikasikan kode + website (repo publik = syarat open-source)

Cara paling gampang sekaligus memenuhi syarat open-source:

1. Buat repo publik baru di GitHub, misal `tipboard`.
2. Upload ke root repo: `index.html` (isi folder `web/`), `TipBoard.sol`, `README.md`, `DEPLOY.md`.
3. Aktifkan **GitHub Pages**: Settings → Pages → Source: branch `main`, folder `/(root)` — website langsung online dengan URL `https://<username>.github.io/tipboard/`.

(Alternatif website: Netlify Drop / Vercel — tapi repo GitHub tetap perlu dibuat untuk syarat open-source.)

## 5. Submit ke hackathon (sebelum 9 Des 2026, 15:00 WIB)

Kirim data berikut di formulir submission resmi (dari pengumuman Binance):

- **Project name:** TipBoard
- **Website:** URL GitHub Pages kamu
- **Contract address:** alamat kontrak dari langkah 1
- **Agent ID usage description** (boleh pakai teks ini):

  > TipBoard is a tipping and message board dApp on BNB Chain built entirely around Agent ID. The contract checks on-chain — via balanceOf() on the official SPACE ID Agent ID contract (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F) — that BOTH the sender and the recipient of a tip hold an Agent ID, and only Agent ID holders can post to the board. Agent ID is therefore not an add-on but the access layer of the product: identity decides who can act. Every tip and post is an on-chain interaction by a verified Agent ID address. The contract has no owner or admin keys; only a tip's recipient can withdraw their own tips, and users confirm every transaction in their own wallet.

## 6. Setelah live — kejar 30 interaksi Agent ID

Syarat Innovation Award: produk live + **≥30 alamat Agent ID berinteraksi** selama periode lomba.

- Posting link website + kontrak di X pakai draf di README.md (#BinanceWalletHackathon #AgenticWallet) — postingan itu juga ikut kampanye X terpisah (2.000 USDC / 20 pemenang), jangan lupa submit link X-nya ke formulir kampanye resmi.
- Bagikan ke komunitas Binance Wallet / BNB Chain; fungsi `postMessage` gratis (cuma gas) jadi orang bisa ikut interaksi tanpa keluar BNB.
- Pantau jumlah interaksi di BscScan (tab Events / daftar transaksi ke kontrak).

## Catatan jujur

- Kontrak ini starter yang sederhana dan **belum diaudit** — fungsinya sempit (tip, post, withdraw) dan tidak ada kunci admin, tapi tetap perlakukan sebagai proyek hackathon, bukan produk finansial.
- Menang tidak dijamin; bagian tersulit adalah distribusi (30 pemegang Agent ID), bukan kodenya.
